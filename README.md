# OmakubPy

Turn a fresh Ubuntu installation into a fully-configured, beautiful, and modern **Python development system** by running a single command.

That’s the one-line pitch for OmakubPy. No need to write bespoke configs for every essential tool just to get started or to be up on all the latest command-line tools. OmakubPy is an opinionated take on what Linux can be at its best — adapted for Python developers.

OmakubPy is based on [Omakub](https://github.com/basecamp/omakub) by Basecamp.
